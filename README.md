# Habi Web Designs

A responsive multi-page website starter for Habi Web Designs.

## Pages
- Home
- Services
- Projects
- Rates
- About
- Process
- Contact
- 404

## Run locally
This is intentionally dependency-light. You can open `index.html` directly for a basic preview, or serve the folder with any static server.

For example:

```bash
python -m http.server 8080
```

Then open `http://localhost:8080`.

## Replace your portfolio
Project cards are currently sample content. Update the project data in `projects.html` or convert the cards into a JSON/data-driven structure when moving to React.

## Contact form
The contact form is frontend-only. Connect it to Formspree, EmailJS, a serverless function, or your own backend before launch.
